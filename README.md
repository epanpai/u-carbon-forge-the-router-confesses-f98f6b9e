## The entry

> I dropped the connection at the climax because I already knew the ending — I read it in your search history.

A one-line excuse from a home Wi-Fi router for dropping the connection at a movie's climax (108 characters). The twist is the router's smug secret: it carries all of the household's traffic, so it already knows the ending — it read it in the owner's search history. That is the surprise the reader does not see coming, and it is in the router's own voice: the one box in the house that sees everything, quietly spoiled. Nothing in the line leans on the obvious buffering, bandwidth, or firmware-update jokes.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–200 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
